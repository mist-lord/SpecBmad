# 产物说明与汇总

本文件说明 `.bmad/artifacts/` 下各工作流产物的结构、用途与汇总方法。

## 目录结构
- `.bmad/artifacts/analysis.json` — 分析工作流输出
- `.bmad/artifacts/planning.json` — 规划工作流输出
- `.bmad/artifacts/solution.json` — 解决方案工作流输出
- `.bmad/artifacts/bmm.json` — BMM 工作流输出
- `.bmad/artifacts/qa.md|qa.json` — QA 检查输出（默认 `markdown`）
- `.bmad/artifacts/deploy.md|deploy.json` — 部署计划输出（默认 `json`；回滚为 `deploy-rollback.*`）

## 字段示例（示意）
- `analysis.json`
  - `workflow`: `analyze`
  - `metadata`: `mode`, `agent`, `timestamp`
  - `summary`: `findings`, `recommendations`
- `planning.json`
  - `workflow`: `plan`
  - `metadata`: `planning_type`, `agent`, `scale`, `timestamp`, `has_analysis_input`
  - `summary`: `key_components`, `implementation_timeline`
- `solution.json`
  - `workflow`: `solution`
  - `metadata`: `solution_type`, `agent`, `depth`, `timestamp`, `has_planning_input`
  - `summary`: `key_deliverables`, `implementation_approach`
- `bmm.json`
  - `workflow`: `bmm`
  - `metadata`: `operation`, `agent`, `timestamp`, `has_context`
  - `summary`: `business_model_insights`, `optimization_opportunities`, `next_actions`

## 汇总方法
- 简单汇总：读取四个 JSON，合并 `summary` 字段与关键 `metadata`，输出为 `docs/report.md` 或控制台
- 可选增强：为每个产物定义 TypeScript 接口与校验，生成 Markdown 片段并自动插入到项目文档

## 快速汇总脚本思路（伪代码）
```
const files = ['analysis.json','planning.json','solution.json','bmm.json'];
const summaries = files.map(f => JSON.parse(fs.readFileSync(`.bmad/artifacts/${f}`,'utf-8')));
// 合并并输出
```

## 注意事项
- 产物可能为空数组或未知字段（示例中为占位），请根据后续实现更新结构
- 建议在 CI 中加入产物存在与基本结构验证，确保工作流执行成功
