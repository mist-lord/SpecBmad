# SpecKit-BMAD 快速开始（简化版）

**目标**: 让您在 1 分钟内开始使用工具，无需任何配置！

---

## 🚀 最简单的方式（推荐）

### 一句话开始

```bash
# 安装依赖（首次使用）
pnpm install && pnpm build

# 一句话生成完整项目
node dist/index.js go "创建一个待办事项应用"
```

就这么简单！工具会自动：
- ✅ 初始化项目配置
- ✅ 检测项目类型和语言
- ✅ 配置 LLM（自动使用 Mock 或真实 API）
- ✅ 执行完整工作流（需求→分析→规划→任务→实现→QA）
- ✅ 生成所有产物

---

## 📋 其他常用场景

### 1. 仅需求分析

```bash
node dist/index.js analyze "构建一个 REST API 服务"
```

### 2. 仅技术规划


```bash

```

## 💡 使用真实 AI（可选）

如果您有 LLM API Key，设置环境变量即可自动使用：

```bash
# 使用 OpenAI
export OPENAI_API_KEY="your-key-here"
node dist/index.js go "创建一个待办事项应用"

# 或使用 Claude
export ANTHROPIC_API_KEY="your-key-here"
node dist/index.js go "创建一个待办事项应用"
```

**没有 API Key？** 没问题！工具会自动使用离线 Mock 模式，功能完全可用。

## ❓ 常见问题

### Q: 需要先运行 `init` 吗？
**A:** 不需要！`go` 命令会自动初始化项目。

### Q: 需要配置 LLM API Key 吗？
**A:** 不需要！工具会自动使用 Mock 模式。有 API Key 时自动使用真实 AI。

### Q: 如何自定义配置？
**A:** 运行 `node dist/index.js config --interactive` 进行交互式配置。

### Q: 如何查看所有命令？
**A:** 运行 `node dist/index.js --help`
