## 命令执行流程

### 完整命令执行流程图

```mermaid
sequenceDiagram
    participant User as 用户
    participant CLI as CLI 入口
    participant Cmd as 命令处理器
    participant AutoInit as 自动初始化
    participant Config as 配置管理器
    participant LLM as LLM 管理器
    participant Agent as Agent 代理
    participant FS as 文件系统
    
    User->>CLI: 执行命令 (如: go "需求")
    CLI->>CLI: 解析命令参数
    CLI->>Cmd: 路由到对应命令
    
    alt 需要初始化
        Cmd->>AutoInit: ensureProjectInitialized()
        AutoInit->>Config: 检查配置是否存在
        alt 配置不存在
            AutoInit->>AutoInit: 检测项目类型/语言
            AutoInit->>Config: 创建默认配置
        end
        AutoInit->>AutoInit: 检查是否需要迁移
        alt 需要迁移
            AutoInit->>AutoInit: 执行配置迁移
        end
    end
    
    Cmd->>LLM: 初始化 LLM 管理器
    LLM->>LLM: 检查环境变量
    LLM->>LLM: 注册可用客户端
    alt 无可用客户端
        LLM->>LLM: 注册 Mock 客户端
    end
    
    Cmd->>Agent: 创建 Agent 实例
    Agent->>LLM: 获取 LLM 客户端
    Agent->>LLM: 调用 LLM 生成响应
    LLM-->>Agent: 返回生成结果
    Agent->>FS: 保存产物到文件
    Agent-->>Cmd: 返回执行结果
    Cmd->>FS: 更新工作流状态
    Cmd-->>User: 输出结果
```

#### 2. `quick` 命令（快速生成）

```mermaid
flowchart TD
    START[quick 命令] --> PARSE[解析需求文本]

    CHOOSE --> GEN[生成项目骨架]
```

#### 3. `workflow` 命令（工作流执行）

```mermaid
flowchart TD
    START[workflow 命令] --> LOAD[加载工作流定义]

    RESUME -->|是| LOAD_STATE[加载工作流状态]
    RESUME -->|否| NEW[创建新工作流]
    LOAD_STATE --> ORC[Orchestrator 执行]
    NEW --> ORC
    ORC --> RESOLVE[解析依赖关系]
    RESOLVE --> EXEC_STEP[执行步骤]
    EXEC_STEP --> PERSIST[持久化状态]
    PERSIST --> MORE{还有步骤?}
    MORE -->|是| EXEC_STEP
    MORE -->|否| SUMMARY[生成摘要]
    SUMMARY --> END[完成]
```

## 工作流执行流程

### Orchestrator 工作流程

```mermaid
flowchart TD
    START[executeWorkflow] --> INIT[初始化 LLM Manager]
    INIT --> REG[注册内置代理]
    REG --> LOAD_CTX[加载初始上下文]
    LOAD_CTX --> RESOLVE[解析执行顺序]
    RESOLVE --> CHECK_DEPS[检查依赖关系]
    CHECK_DEPS --> TOPO[生成拓扑排序]
    TOPO --> LOOP[遍历步骤]
    LOOP --> CHECK_COMPLETE{步骤已完成?}
    CHECK_COMPLETE -->|是| SKIP[跳过]
    CHECK_COMPLETE -->|否| UPDATE_CTX[更新上下文]
    SKIP --> NEXT
    UPDATE_CTX --> CREATE_AGENT[创建 Agent]
    CREATE_AGENT --> EXEC[执行 Agent]
    EXEC --> RETRY{需要重试?}
    RETRY -->|是| EXEC
    RETRY -->|否| SUCCESS{成功?}
    SUCCESS -->|是| SAVE_STATE[保存状态]
    SUCCESS -->|否| FAIL_STATE[保存失败状态]
    SAVE_STATE --> NEXT[下一个步骤]
    FAIL_STATE --> ERROR[抛出错误]
    NEXT --> MORE{还有步骤?}
    MORE -->|是| LOOP
    MORE -->|否| FINAL[更新最终状态]
    FINAL --> RETURN[返回结果]
    ERROR --> RETURN
```

```mermaid
    CHECK_CYCLE -->|是| ERROR[抛出错误]
    CHECK_CYCLE -->|否| ORDER[生成执行顺序]
```

### LLM 调用流程

```mermaid
sequenceDiagram
    participant Agent as Agent
    participant Manager as LLMManager
    participant Client as LLM Client
    participant API as LLM API
    
    Agent->>Manager: getDefaultClient()
    Manager->>Manager: 查找可用客户端
    alt 有可用客户端
        Manager-->>Agent: 返回客户端
    else 无可用客户端
        Manager->>Manager: 创建 Mock 客户端
        Manager-->>Agent: 返回 Mock 客户端
    end
    
    Agent->>Client: generateText(prompt, options)
    alt Mock 客户端
        Client->>Client: 生成模拟响应
        Client-->>Agent: 返回模拟结果
    else 真实客户端
        Client->>API: 发送 API 请求
        API-->>Client: 返回响应
        Client->>Client: 解析响应
        Client-->>Agent: 返回结果
    end
```

## 总结

### 核心设计原则

1. **模块化设计**: 各组件职责清晰，低耦合高内聚
2. **可扩展性**: 通过工厂模式支持新 Agent 和 LLM 客户端
3. **容错性**: Mock 模式支持离线使用，自动降级
4. **状态管理**: 工作流状态持久化，支持恢复
5. **自动化**: 自动初始化、自动配置、自动检测

### 关键数据流

1. **用户输入** → **命令解析** → **工作流编排** → **Agent 执行** → **LLM 生成** → **文件输出**
2. **配置加载** → **LLM 初始化** → **Agent 注册** → **上下文构建** → **执行** → **状态更新**

### 扩展点

1. **新增 Agent**: 继承 `BaseAgent`，在 `registerBuiltInAgents` 中注册
2. **新增 LLM**: 实现 `LLMClient` 接口，在 `LLMManager` 中注册
3. **新增命令**: 在 `src/index.ts` 中注册，实现命令处理函数
4. **新增模板**: 在 `src/generator/templates/` 中添加模板清单
