# SpecKit-BMAD 支持的语言和场景

## 📚 支持的编程语言

### 核心支持（已实现）

| 语言 | 检测方式 | 框架支持 | 状态 |
|------|---------|---------|------|
| **TypeScript** | `package.json`、`tsconfig.json` | React, Next.js, NestJS, Express | ✅ 完全支持 |
| **JavaScript** | `package.json` | React, Vue, Svelte, Express | ✅ 完全支持 |
| **Python** | `requirements.txt`、`setup.py`、`pyproject.toml` | Flask, FastAPI, Django | ✅ 完全支持 |
| **C++** | `CMakeLists.txt`、`Makefile`、`.cpp/.hpp` 文件 | 标准库、CMake | ✅ 基础支持 |
| **Go** | `go.mod` | 标准库、Gin, Echo | ✅ 基础支持 |
| **Rust** | `Cargo.toml` | 标准库、Tokio, Actix | ✅ 基础支持 |

### 扩展支持（可通过配置）

- **Java** (通过配置文件指定)
- **C#** (通过配置文件指定)
- **Ruby** (通过配置文件指定)
- **PHP** (通过配置文件指定)

## 🚀 快速栈选择

工具支持以下预定义栈（通过 `quick` 命令）：

| 栈类型 | 说明 | 语言 | 框架 |
|--------|------|------|------|
| `ts-cli` | TypeScript 命令行工具 | TypeScript | Node.js |
| `ts-api` | TypeScript API 服务 | TypeScript | Express/NestJS |
| `py-cli` | Python 命令行工具 | Python | 标准库 |
| `cpp-cli` | C++ 命令行工具 | C++ | CMake |
| `cpp-app` | C++ 应用程序 | C++ | CMake |
| `ts-chat` | TypeScript 聊天应用 | TypeScript | WebSocket |

**自动选择逻辑**：
- 包含 "api"、"接口"、"服务" → `ts-api`
- 包含 "python"、"py" → `py-cli`
- 包含 "c++"、"cpp" → `cpp-cli` 或 `cpp-app`（根据是否包含 GUI/界面关键词）
- 包含 "chat"、"聊天" → `ts-chat`
- 默认 → `ts-cli`

**使用示例**：
```bash
# 自动选择栈
node dist/index.js quick --text "创建一个 HTTP API 服务"

# 手动指定栈
node dist/index.js quick --text "创建一个工具" --stack ts-cli
```

## 🔧 如何扩展支持

### 添加新语言

1. **在 `auto-init.ts` 中添加检测逻辑**：
```typescript
// 检查新语言
if (fs.existsSync(path.join(cwd, '新语言的配置文件'))) {
  return '新语言';
}
```

2. **在 `args-validator.ts` 中添加验证**：
```typescript
const allowedLangs = ['typescript', 'javascript', 'python', 'go', 'rust', '新语言'];
```

3. **创建对应的生成器模板**（在 `generator/templates/` 目录）

### 添加新场景

1. **创建自定义代理**：
```bash
node dist/index.js agents --create Writer
```

2. **定义工作流**：
```json
{
  "workflows": {
    "content-creation": {
      "steps": [
        { "agent": "Writer", "input": {...} }
      ]
    }
  }
}
```

3. **使用自定义工作流**：
```bash
node dist/index.js workflow --name content-creation
```

## 📝 写作场景详细说明

### 当前支持的写作类型

1. **技术文档**
   - 需求规格文档
   - API 文档
   - 架构设计文档
   - 用户手册

2. **项目文档**
   - 项目说明书
   - 开发指南
   - 部署文档
   - 测试文档

### 如何启用创意写作

**方法 1: 使用自定义代理**
```bash
# 1. 创建 Writer 代理配置
# 编辑 .specbmad/config.json，添加：
{
  "agents": {
    "Writer": {
      "type": "Writer",
      "enabled": true,
      "model": "gpt-4",
      "capabilities": ["creative-writing", "content-creation"]
    }
  }
}

# 2. 使用 Writer 代理
node dist/index.js analyze --agent Writer --mode creative
```

**方法 2: 使用 BMAD-Method 的 CIS 模块**
```bash
# 配置启用 CIS 模块
node dist/index.js config --set bmad_method.active_modules='["bmm","cis"]'

# 使用创意工作流
node dist/index.js workflow --name creative-workflow
```
