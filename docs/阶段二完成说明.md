# 阶段二完成说明

本文件标记阶段二（AI代理编排与工作流命令）核心项已完成，并提供使用示例与常见问题答疑。

## 已完成功能
- 工作流编排：内置 `planning-only`、`full-development` 工作流可用
- 代理工厂与注册：内置代理自动注册，按步骤加载与执行
- 工作流命令：支持 `--format markdown|json` 与 `--report-dir` 自动文件名
- 配置扩展：支持在项目配置中定义自定义工作流，优先于内置定义
- 总结输出：生成 Markdown 与 JSON 摘要（步骤、代理、执行状态、耗时）
- CLI 测试：覆盖 Markdown/JSON 输出与边界/失败路径

## 使用示例
- 运行内置工作流（Markdown 输出到目录自动命名）：
  - `node dist/index.js workflow --name planning-only --format markdown --report-dir .bmad/artifacts`
  - 产物：`.bmad/artifacts/workflow.md`
- 运行内置工作流（JSON 输出到目录自动命名）：
  - `node dist/index.js workflow --name planning-only --format json --report-dir .bmad/artifacts`
  - 产物：`.bmad/artifacts/workflow.json`
- 指定完整输出文件路径：
  - `node dist/index.js workflow --name full-development --format markdown --output docs/最新运行报告.md`
- 从配置读取自定义工作流：
  - 在项目配置（`config.getAll()`）中添加：
    ```json
    {
      "workflows": {
        "custom-demo": {
          "description": "演示工作流",
          "steps": [
            { "id": "s1", "name": "规划", "agent": "Planner" },
            { "id": "s2", "name": "实现", "agent": "Developer" },
            { "id": "s3", "name": "质量", "agent": "QA" }
          ]
        }
      }
    }
    ```
  - 运行：`node dist/index.js workflow --name custom-demo --format markdown --report-dir .bmad/artifacts`

## 常见问题（FAQ）
- Q: 未指定 `--output` 或 `--report-dir` 会怎样？
  - A: 控制台打印摘要（截断版），不写入文件。
- Q: `--format` 传入非 `markdown|json` 的值会怎样？
  - A: 自动回退为 `json`，产物文件名为 `workflow.json`。
- Q: 配置里定义的代理名不正确（未注册）会怎样？
  - A: 编排阶段快速失败并报错，提示未找到代理。
- Q: 未发现默认 LLM 客户端会怎样？
  - A: 命令提示 `未找到可用的默认 LLM 客户端` 并退出。
- Q: 如何与其他命令产物保持一致？
  - A: `workflow` 的 `--report-dir` 与 `tasks/implement/qa` 的目录/自动文件名策略一致，分别生成 `workflow.md` 或 `workflow.json`。
