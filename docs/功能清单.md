# SpecBmad 项目功能清单

基于 Unified Architecture v2 架构分析

## 一、核心架构层（Phase 0-5 状态机）

### 1.1 Phase Controller
- **功能**: Phase 状态管理、迁移控制、Gate 检查
- **文件**: `src/core/phase/controller.ts`
- **关键方法**:
  - `getCurrentPhase()`: 获取当前 Phase
  - `canTransitionTo(targetPhase)`: 检查是否可以迁移
  - `transitionTo(targetPhase, context)`: 执行 Phase 迁移
  - `checkGates(phase, context)`: 检查 Gate

### 1.2 Event Store
- **功能**: 事件存储、查询、回放
- **文件**: `src/core/events/store.ts`
- **关键方法**:
  - `appendEvent(event)`: 追加事件
  - `queryEvents(filter)`: 查询事件
  - `getPhaseHistory(phase)`: 获取 Phase 历史
  - `replayEvents(filter)`: 回放事件

### 1.3 Gate 机制
- **功能**: OpenSpec Gate、DeepCode Gate、Verification Gate
- **文件**: `src/core/phase/gates.ts`
- **Gate 类型**:
  - `openspec_passed`: Phase 1→2 的 Gate
  - `deepcode_passed`: Phase 3→4 的 Gate
  - `verification_passed`: Phase 4→5 的 Gate

## 二、Spec Domain（规范域）

### 2.1 Spec-Kit 集成
- **功能**: Phase 0 - Intent Capture，生成 intent.yaml
- **文件**: `src/core/spec/spec-kit.ts`
- **关键方法**:
  - `execute(options)`: 执行 Spec-Kit

### 2.2 OpenSpec 集成
- **功能**: Phase 1 - Formal Specification，生成 formal_spec.yaml
- **文件**: `src/core/spec/openspec.ts`
- **关键方法**:
  - `execute(options)`: 执行 OpenSpec
  - `OpenSpecGateChecker`: Gate 检查器

### 2.3 Spec 保护机制
- **功能**: Execution Domain 禁止修改 Spec
- **文件**: `src/core/spec/protection.ts`
- **关键方法**:
  - `checkWritePermission(filePath)`: 检查写入权限
  - `checkDeletePermission(filePath)`: 检查删除权限

### 2.4 Spec Schema
- **功能**: 定义 intent.yaml 和 formal_spec.yaml 的类型
- **文件**: `src/core/spec/schema.ts`

## 三、Execution Domain（执行域）

### 3.1 Orchestrator
- **功能**: 工作流编排（传统步骤模式 + Phase 驱动模式）
- **文件**: `src/core/workflow/orchestrator.ts`
- **关键方法**:
  - `executeWorkflow()`: 传统步骤模式
  - `executePhaseWorkflow()`: Phase 驱动模式

### 3.2 Agent 系统
- **功能**: 多角色 Agent 协作
- **文件**: `src/agents/`
- **Agent 类型**:
  - `AnalystAgent`: 需求分析
  - `ArchitectAgent`: 架构设计
  - `DeveloperAgent`: 代码实现
  - `QAAgent`: 质量保证
  - `ScrumMasterAgent`: Scrum 管理
  - `SecurityExpertAgent`: 安全专家

### 3.3 Agent Factory
- **功能**: Agent 注册与实例化
- **文件**: `src/agents/factory.ts`

### 3.4 代码生成器
- **功能**: 多语言模板生成（TS, Python, C++）
- **文件**: `src/generator/index.ts`

## 四、Intelligence Domain（智能域）

### 4.1 LLM Manager
- **功能**: LLM 客户端管理（OpenAI, Claude, Mock）
- **文件**: `src/core/llm/manager.ts`
- **关键功能**:
  - 客户端初始化
  - 默认客户端选择
  - 客户端注册

### 4.2 LLM 客户端
- **文件**: `src/core/llm/clients/`
- **客户端类型**:
  - `OpenAIClient`: OpenAI API
  - `ClaudeClient`: Claude API
  - `MockClient`: Mock 模式（离线测试）

### 4.3 LLM 缓存
- **功能**: LLM 响应缓存
- **文件**: `src/core/llm/cache.ts`

### 4.4 LLM 并发控制
- **功能**: 并发请求限制
- **文件**: `src/core/llm/concurrency.ts`

### 4.5 DeepCode 集成
- **功能**: Phase 3/4 - 代码验证
- **文件**: `src/core/verification/deepcode.ts`
- **关键方法**:
  - `execute(options)`: 执行 DeepCode 验证
  - `DeepCodeGateChecker`: Gate 检查器

### 4.6 Python 桥接
- **功能**: 调用 Python 脚本（Spec-Kit, OpenSpec, DeepCode）
- **文件**: `src/core/bridge/python.ts`
- **关键方法**:
  - `execute(options)`: 执行 Python 脚本
  - `isAvailable()`: 检查 Python 是否可用
